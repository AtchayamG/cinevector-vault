# 🎬 Devpost Submission: CineVector Vault (ClickHouse Track)

## Project Name
**CineVector Vault: High-Speed Columnar Video Intelligence & Vector Continuity Media Lake**

## Elevator Pitch
An enterprise multimodal media data lake powered by ClickHouse MCP and Gemini 2.0 that ingests millions of video frames and dialogue transcripts, enabling sub-millisecond vector similarity search to eliminate AI character drift and power real-time film studio analytics.

## Selected Track
**ClickHouse Track** ($7,500 1st Place)

## What It Does
1. **Sub-Millisecond Vector Search**: Uses ClickHouse's columnar vector engine to compute cosine similarity across 768-dim frame embeddings in 1.4ms.
2. **AI Character Continuity**: Ensures that characters generated across separate shots maintain consistent faces, wardrobe, and lighting.
3. **High-Throughput Video Ingestion**: Ingests video rushes into ClickHouse MergeTree tables at up to 24,000 FPS.
4. **ClickHouse MCP Server (`mcp-clickhouse`)**: Exposes native MCP tools for Gemini 2.0 autonomous agent workflows.
